# claude-cast

🇬🇧 [Read in English](README.md)

Конвертация JSONL-логов Claude Code в терминальные скринкасты.

Берёт необработанный лог сессии Claude Code и создаёт реалистичный терминальный скринкаст, показывающий работу Claude — с вызовами инструментов, редактированием файлов, bash-командами и подписями к действиям.

## Установка

```bash
npm install
npm run build
```

## Использование

```bash
# Базовое: JSONL → asciicast
npx claude-cast input.jsonl -o output.cast

# С параметрами
npx claude-cast input.jsonl -o output.cast --speed 2 --max-pause 5

# Вывод в GIF (требуется agg: cargo install agg)
npx claude-cast input.jsonl -o output.gif

# Вывод в MP4 (требуется agg + ffmpeg)
npx claude-cast input.jsonl -o output.mp4
```

## Параметры

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| `-o, --output <path>` | `output.cast` | Путь к выходному файлу |
| `-f, --format <fmt>` | `cast` | Формат вывода: `cast`, `gif`, `mp4` |
| `-s, --speed <n>` | `1` | Множитель скорости воспроизведения |
| `--max-pause <sec>` | `3` | Максимальная длительность паузы (секунды) |
| `--width <cols>` | `120` | Ширина терминала |
| `--height <rows>` | `40` | Высота терминала |
| `--typing-speed <cps>` | `80` | Скорость набора — запасное значение (символы/сек) |
| `--user-typing-speed <cps>` | `80` | Скорость набора сообщений пользователя (символы/сек) |
| `--agent-speed <cps>` | `80` | Скорость tool_use/tool_result агента (символы/сек) |
| `--response-typing-speed <cps>` | `80` | Скорость вывода ответа ассистента (символы/сек) |
| `--response-pause <sec>` | `0` | Пауза после ответа ассистента (секунды) |
| `--no-captions` | `false` | Отключить подписи к действиям |

### Пофазная настройка скорости

Разные фазы сессии Claude воспроизводятся с разной скоростью для более естественного просмотра:

| Фаза | Описание | Рекомендуемая скорость |
|------|----------|------------------------|
| Ввод пользователя | Медленно — зритель читает промпт | ~30 симв/сек |
| Работа агента | Быстрая прокрутка цепочек инструментов | ~500 симв/сек |
| Текст ассистента | Читаемая скорость вывода | ~60 симв/сек |
| Пауза после ответа | Передышка перед следующим ходом | ~2 сек |

Пример:
```bash
npx claude-cast input.jsonl -o output.cast \
  --user-typing-speed 30 \
  --agent-speed 500 \
  --response-typing-speed 60 \
  --response-pause 2
```

Если пофазные параметры не указаны, для всех фаз используется `--typing-speed`.

### Рекомендуемые настройки

Эти подобранные значения дают хорошо сбалансированный скринкаст:

```bash
npx claude-cast input.jsonl -o output.cast \
  --user-typing-speed 25 \
  --agent-speed 800 \
  --response-typing-speed 50 \
  --response-pause 3 \
  --max-pause 4 \
  --speed 1.5
```

Почему эти значения хорошо работают:

- **`--user-typing-speed 25`** — достаточно медленно, чтобы зритель успел прочитать промпт по мере его появления
- **`--agent-speed 800`** — вызовы инструментов и результаты прокручиваются быстро; зрителю не нужно читать каждую строку, достаточно видеть активность
- **`--response-typing-speed 50`** — ответы Claude появляются в комфортном для чтения темпе
- **`--response-pause 3`** — 3-секундная передышка между ходами, чтобы зритель мог осмыслить ответ
- **`--max-pause 4`** — ограничивает мёртвое время, запись никогда не зависает
- **`--speed 1.5`** — лёгкое глобальное ускорение, подтягивающее общий темп без ощущения спешки

```bash

```

## Где найти логи Claude Code

Логи Claude Code хранятся в `~/.claude/projects/*/logs/`. Каждая сессия создаёт JSONL-файл с записями сообщений с метками времени.

## Конвейер обработки

1. **Парсер** — читает JSONL-лог, извлекает структурированные события (вызовы инструментов, текст, результаты)
2. **Таймлайн** — строит упорядоченный список событий, объединяет смежные текстовые блоки
3. **Компрессор** — ограничивает длинные паузы, обрезает большие выводы, применяет скорость
4. **Рендерер** — генерирует кадры asciicast v2 с оформлением терминала и подписями
5. **Экспортёр** — записывает файл `.cast`; при необходимости конвертирует в GIF/MP4

## Форматы вывода

- **`.cast`** (asciicast v2) — нативный формат, воспроизводится через `asciinema play` или веб-плеер. Без внешних зависимостей.
- **`.gif`** — требуется [agg](https://github.com/asciinema/agg) (`cargo install agg`)
- **`.mp4`** — требуется agg + [ffmpeg](https://ffmpeg.org/)
