# claude-cast

🇬🇧 [Read in English](README.md)

Конвертация JSONL-логов Claude Code в терминальные скринкасты.

Берёт необработанный лог сессии Claude Code и создаёт реалистичный терминальный скринкаст, показывающий работу Claude — с вызовами инструментов, редактированием файлов, bash-командами и подписями к действиям.

## Установка

```bash
npm install
npm run build
```

## Использование

```bash
# Базовое: JSONL → asciicast
npx claude-cast input.jsonl -o output.cast

# С параметрами
npx claude-cast input.jsonl -o output.cast --speed 2 --max-pause 5

# Вывод в GIF (требуется agg: cargo install agg)
npx claude-cast input.jsonl -o output.gif

# Вывод в MP4 (требуется agg + ffmpeg)
npx claude-cast input.jsonl -o output.mp4
```

## Параметры

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| `-o, --output <path>` | `output.cast` | Путь к выходному файлу |
| `-f, --format <fmt>` | `cast` | Формат вывода: `cast`, `gif`, `mp4` |
| `-s, --speed <n>` | `2` | Множитель скорости воспроизведения |
| `--max-pause <sec>` | `4` | Максимальная длительность паузы (секунды) |
| `--width <cols>` | `120` | Ширина терминала |
| `--height <rows>` | `40` | Высота терминала |
| `--typing-speed <cps>` | `80` | Скорость набора — запасное значение (символы/сек) |
| `--user-typing-speed <cps>` | `25` | Скорость набора сообщений пользователя (символы/сек) |
| `--agent-speed <cps>` | `800` | Скорость tool_use/tool_result агента (символы/сек) |
| `--response-typing-speed <cps>` | `75` | Скорость вывода ответа ассистента (символы/сек) |
| `--response-pause <sec>` | `5` | Пауза после ввода пользователя (секунды) |
| `--pre-user-pause <sec>` | `4` | Пауза перед вводом пользователя (секунды) |
| `--captions` | `false` | Включить подписи к действиям (по умолчанию выключены) |

### Пофазная настройка скорости

Разные фазы сессии Claude воспроизводятся с разной скоростью для более естественного просмотра:

| Фаза | Описание | По умолчанию |
|------|----------|--------------|
| Ввод пользователя | Пословно — зритель читает промпт | 25 симв/сек |
| Работа агента | Быстрая построчная прокрутка цепочек инструментов | 800 симв/сек |
| Текст ассистента | Пословный читаемый поток вывода | 75 симв/сек |
| Пауза после ввода | Передышка после ввода пользователя | 5 сек |
| Пауза перед вводом | Пауза перед следующим вводом пользователя | 4 сек |

Сообщения пользователя и ответы ассистента выводятся **пословно** для естественного ощущения набора. Вывод инструментов (результаты bash, содержимое файлов) остаётся **построчным**, так как это машинный вывод.

Если пофазные параметры не указаны, для всех фаз используется `--typing-speed`.

### Почему эти значения по умолчанию работают

Значения по умолчанию подобраны для получения компактного, удобного для просмотра скринкаста:

- **`--speed 2`** — 2x глобальное ускорение сжимает общий темп, чтобы вывод bash/инструментов пролетал быстро, а ввод пользователя и ответы ассистента получают паузы благодаря пофазным скоростям
- **`--user-typing-speed 25`** — промпты пользователя появляются пословно в медленном темпе, чтобы зритель успел их прочитать
- **`--agent-speed 800`** — вызовы инструментов и результаты прокручиваются быстро; зрителю не нужно читать каждую строку, достаточно видеть активность
- **`--response-typing-speed 75`** — ответы Claude появляются пословно в комфортном для чтения темпе
- **`--response-pause 5`** — заметная пауза после ввода пользователя, чтобы зритель успел прочитать промпт перед тем как агент начнёт работать
- **`--pre-user-pause 4`** — пауза перед следующим вводом пользователя, чтобы зритель успел осмыслить ответ агента
- **`--max-pause 4`** — ограничивает мёртвое время, запись никогда не зависает

Для переопределения передайте любой параметр в командной строке:

```bash
# Медленный, расслабленный темп
npx claude-cast input.jsonl -o output.cast --speed 1 --user-typing-speed 15

# Быстрый демо-темп
npx claude-cast input.jsonl -o output.cast --speed 3 --pre-user-pause 3
```

## Воспроизведение

```bash
# С помощью asciinema
asciinema play output.cast

# Или загрузить на asciinema.org для веб-плеера
asciinema upload output.cast
```

## Где найти логи Claude Code

Логи Claude Code хранятся в `~/.claude/projects/*/logs/`. Каждая сессия создаёт JSONL-файл с записями сообщений с метками времени.

## Конвейер обработки

1. **Парсер** — читает JSONL-лог, извлекает структурированные события (вызовы инструментов, текст, результаты)
2. **Таймлайн** — строит упорядоченный список событий, объединяет смежные текстовые блоки
3. **Компрессор** — ограничивает длинные паузы, обрезает большие выводы, применяет скорость
4. **Рендерер** — генерирует кадры asciicast v2 с оформлением терминала и подписями
5. **Экспортёр** — записывает файл `.cast`; при необходимости конвертирует в GIF/MP4

## Форматы вывода

- **`.cast`** (asciicast v2) — нативный формат, воспроизводится через `asciinema play` или веб-плеер. Без внешних зависимостей.
- **`.gif`** — требуется [agg](https://github.com/asciinema/agg) (`cargo install agg`)
- **`.mp4`** — требуется agg + [ffmpeg](https://ffmpeg.org/)
